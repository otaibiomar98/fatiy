# مستقبل فتي · شباب تاسع

منصة شباب تاسع: الرئيسية، لوحة النقاط، ترتيب الخواطر، أهداف المشتركين، اللجان، المكتبة، نقطة تحوّل.

## النشر على GitHub Pages (مرة واحدة)
1. ادخل github.com ← New repository ← الاسم مثلاً `fatiy` ← Public ← Create.
2. في المستودع: Add file ← Upload files ← اسحب **محتويات** هذا المجلد (index.html و data.json ومجلد images) ← Commit changes.
3. Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save.
4. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/fatiy/`

## التعديل من المنصة (المشرف فقط)
1. github.com ← Settings ← Developer settings ← Fine-grained tokens ← Generate new token.
2. Repository access: Only select repositories ← اختر `fatiy`. Permissions ← Contents: Read and write.
3. افتح المنصة ← زر «المشرف» ← اكتب `اسم-حسابك/fatiy` والمفتاح.
4. عدّل ← «حفظ ونشر». يظهر التحديث للجميع خلال دقيقة أو دقيقتين.

المفتاح يُحفظ على جهاز المشرف فقط. لا ترسله لأحد.
